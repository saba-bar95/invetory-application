# Express Starter Boilerplate

A clean, modern boilerplate template for building web applications with Node.js, Express, EJS, and PostgreSQL. Pre-configured with ES Modules, environment variables, static assets, and custom error handling.

## Features

- **ES Module Support:** Modern `import/export` syntax powered by Node.js.
- **Server-Side Rendering:** EJS templating configured with a structured `views/` directory.
- **Environment Management:** Centralized configuration using `dotenv`.
- **Static Asset Serving:** Built-in public directory setup for CSS, JS, and images.
- **Route Organization:** Modular router setup ready for expanding endpoints.
- **Error Handling:** Pre-configured global 404 and error-handling middleware.

## Tech Stack

- **Runtime:** [Node.js](https://nodejs.org/)
- **Framework:** [Express.js](https://expressjs.com/)
- **View Engine:** [EJS](https://ejs.co/)
- **Utilities:** [dotenv](https://www.npmjs.com/package/dotenv)

## Getting Started

Follow these steps to create a new project using this template.

### Prerequisites

Make sure you have Node.js (v18 or higher) installed on your machine.

- [Node.js Download](https://nodejs.org/)

### Installation & Local Setup

1. **Clone the repository:**

   cd YOUR_REPO_NAME
